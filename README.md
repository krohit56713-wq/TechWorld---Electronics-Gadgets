## 📌 Project Overview
TechWorld is a modern, tech-savvy e-commerce web application developed for the Data Alcott Systems Web Development Internship[cite: 10]. It simulates a full-fledged online store featuring smartphones, laptops, audio devices, smartwatches, and accessories[cite: 10].

---

## 🚀 Features Implemented
- **Category Navigation:** Smartphones, Laptops & Tablets, Audio & Wearables, and Accessories[cite: 9].
- **Real-Time Product Search:** Instant search filter across items and brands.
- **Interactive Cart & Checkout:** Quantity adjustment, price calculation, and tax computation.
- **User Wishlist & Order History:** Simulated user account tracking.
